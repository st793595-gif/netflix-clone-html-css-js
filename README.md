# Netflix Clone 🎬

A Netflix-inspired website built using HTML, CSS, and JavaScript as a frontend web development project.

## Features
- Netflix-inspired user interface
- Navigation bar and search box
- Movie and show content sections
- Hindi and English language toggle
- Help Centre section
- Email form with validation
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Preview
This project recreates the look and feel of a popular streaming platform while practising frontend web development skills.
